## The entry

A stdlib-only Python program (`main.py`, no third-party imports, no
network, fully deterministic) that writes one original roast line about a
smart fridge to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default
`/output`).

The line (140 characters):

> My smart fridge photographs me raiding it at 2am and files the evidence under 'snack incidents' — the only paparazzi who works for leftovers

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
